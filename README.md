# EmployeeHub

A simple Employee and Task Management application built using Angular.

## Features
- Employee list and employee details
- Search employees by name
- Filter employees by department
- View and create tasks
- Login and route protection
- API integration using Angular services


## Run Locally

1. Install dependencies:

   ```bash
   npm install

2. Local server start:

   ```bash
   ng serve
